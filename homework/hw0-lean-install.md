# Homework 0: Lean Installation and Chapter 1 Exercises

This homework sets up Lean 4 and its VS Code development environment, then gives you practice with the material in Chapter 1 of [Functional Programming in Lean](https://lean-lang.org/functional_programming_in_lean/).

## Problems

1. **Install Lean and set up VS Code.** Follow the official [Lean installation guide](https://lean-lang.org/install/), which recommends using the Lean 4 extension for VS Code. The extension is already installed on the course machine; use its Setup Guide to install or select Lean if needed. In VS Code, create and save a file named `chapter-1.lean`, then use the Lean Infoview and inline diagnostics to check your code. You should not need to create a Lake project for these exercises. If the extension prompts you to set up or open a project, follow its instructions.

1. **Complete the Chapter 1 exercises.** Work through all problem exercises in Chapter 1, “Getting to Know Lean,” of [Functional Programming in Lean](https://lean-lang.org/functional_programming_in_lean/). Use the Lean Infoview and inline diagnostics in VS Code to check your work as you go.

## What to submit

Submit the `chapter-1.lean` file with your solutions to all of the Chapter 1 exercises, clearly labeled so they can be matched to the book.
